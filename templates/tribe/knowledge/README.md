# Knowledge {{nama}}

Isi folder ini dari panduan di `../guide/`. Setiap fakta domain wajib bertaut ke slide sumbernya.

| File                  | Isi                                                                                    |
| --------------------- | -------------------------------------------------------------------------------------- |
| `ringkasan.md`        | Satu halaman: produk ini apa, siapa penggunanya, tahapan utamanya                      |
| `glosarium.md`        | Istilah resmi, akronim, dan padanan kodenya                                            |
| `peran-pengguna.md`   | Peran dan hak aksesnya per menu                                                        |
| `alur.md`             | Tahapan dan perpindahan status                                                         |
| `aturan-bisnis.md`    | Aturan dengan ID tetap (`BR-001`, dst.) dan tautan slide                               |
| `status-dan-enum.md`  | Nilai status dan pilihan. Tandai **(turunan)** bila hanya disimpulkan                  |
| `tracker-existing.md` | Tracker yang sudah berjalan dan gap-nya (fakta data: sebutkan tabel dan tanggal ambil) |
| `konteks-project.md`  | Tujuan, kontak koordinasi, dan keputusan penting                                       |

Dilarang menulis data pribadi pengguna (nama, email, NIP, NIK, nomor HP), termasuk sebagai contoh.
